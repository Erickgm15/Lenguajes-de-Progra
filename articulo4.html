¿Qué es SQL?

SQL (Structured Query Language) es un lenguaje diseñado para gestionar y manipular bases de datos. Es el lenguaje estándar para interactuar con bases de datos relacionales como MySQL, PostgreSQL, SQLite y SQL Server.

¿Para qué se usa SQL?

  • Consultar datos (SELECT)
  • Insertar nuevos registros (INSERT)
  • Actualizar datos existentes (UPDATE)
  • Eliminar datos (DELETE)
  • Crear y modificar tablas (CREATE, ALTER)

    • SQL es declarativo, lo que significa que describes qué quieres hacer con los datos, y el sistema de base de datos se encarga de cómo hacerlo.

    Ejemplo

    SELECT nombre, edad FROM estudiantes WHERE edad > 18;
