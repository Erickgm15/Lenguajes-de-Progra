¿Qué es Java?

Java es un lenguaje de programación orientado a objetos, de propósito general y de alto nivel, diseñado para ser portátil, seguro y robusto. Fue desarrollado por Sun Microsystems en 1995 (ahora propiedad de Oracle).

  • Aplicaciones de escritorio
  • Aplicaciones móviles (especialmente en Android)
  • Servidores web y backend (Spring Framework, Java EE)
  • Juegos y simulaciones
  • Sistemas embebidos y dispositivos inteligentes
  • Orientado a objetos Basado en clases y objetos. Facilita la reutilización de código.
  • Portabilidad Funciona en múltiples plataformas gracias a la JVM.
  • Seguridad Restringe accesos inseguros, ideal para aplicaciones en red.
  • Multihilo Permite la ejecución de múltiples tareas al mismo tiempo.
