¿Qué es C#?

C# (se pronuncia "C sharp") es un lenguaje de programación moderno, orientado a objetos, desarrollado por Microsoft en el año 2000 como parte de su plataforma .NET. Combina la potencia de lenguajes como C++ con la simplicidad de lenguajes como Java y Python, ideal para crear aplicaciones robustas y modernas.

¿Para qué se usa C#?

  • Aplicaciones de escritorio (Windows Forms, WPF)
  • Aplicaciones web (ASP.NET)
  • Videojuegos (especialmente con Unity)
  • Aplicaciones móviles (Xamarin, MAUI)
  • APIs y servicios web
  • Automatización y herramientas de productividad
